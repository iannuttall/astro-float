This page is a Markdown file at `src/content/blog/hello-float/index.md`. Nothing about it is special — it is a normal Astro content collection entry.

What *is* different is the little icon in the Astro dev toolbar at the bottom of the window. Click it and a vertical rail docks to the edge of the viewport. From there you can:

- edit this body text and watch the page update without a reload
- change frontmatter fields (title, date, tags, draft) with proper controls
- drop an image in and get a Markdown link back
- create a new post in this collection

## Try it

1. Toggle the Float icon in the dev toolbar.
2. Open **Body**, type a few words below this list.
3. Press ⌘S (or Ctrl+S), or turn on autosave in Settings.

Everything writes straight to disk, so your editor and git see exactly what you see.

## Why not a CMS?

Because most of the time you just want to fix a typo while looking at the page. A separate admin URL, a login, and a database are a lot of ceremony for that.
